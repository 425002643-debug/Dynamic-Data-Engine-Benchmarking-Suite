**Prblem Statement**
  Many School and community libraries still stack books, reserve, borrow, and return using manual logbooks or spreadsheets. As the collection and the number of borrowers grow, searching for books, checking their availability, handling reservation queues, and computing overdue returns become slow and error-prone. Records of past transactions pile up with no structured archive, so old data either clutters the active system or gets lost. A library needs a system that processes these transactions quickly, keeps them in the correct order, and moves old records to an archive without slowing down daily operations.
